# Definition of Done

Uma tarefa só está concluída quando: - Critérios de aceitação
satisfeitos. - Código respeita arquitetura e padrões. - TypeScript sem
erros. - ESLint/Prettier aprovados. - Testes pertinentes executados e
aprovados. - Regras de autorização verificadas. - Isolamento
organizacional testado quando aplicável. - Erros e estados de
carregamento tratados. - Acessibilidade considerada. - Documentação
atualizada. - Nenhuma regressão conhecida introduzida. - Relatório do
agente entregue.

Uma fase só está concluída quando todas as tarefas críticas foram
aprovadas, CI passou, documentação está coerente e o orquestrador
registrou aprovação explícita.
