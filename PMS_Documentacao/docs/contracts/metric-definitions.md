# Definições de métricas

-   Lead Time: criação até conclusão.
-   Cycle Time: início efetivo até conclusão.
-   Throughput: ciclos concluídos no período.
-   Tarefas únicas: IDs distintos.
-   Taxa de conclusão por coorte: tarefas criadas no período que foram
    concluídas até a data de referência / tarefas consideradas na
    coorte.
-   Conclusões no período: tarefas/ciclos concluídos no período,
    independentemente da criação.
-   Tempo total: tempo decorrido.
-   Tempo efetivo: tempo total menos pausas válidas.
-   Reabertura: novo ciclo, mantendo histórico anterior.
-   Dados insuficientes: apresentar indisponível, nunca zero implícito.
